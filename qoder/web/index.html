🏗️ 关于 SmartStudy

项目简介

SmartStudy 是一个智能学习教练，帮助学习者记录学习过程、管理知识记忆、获取个性化复习建议。 通过集成 PowerContext 上下文服务，系统能够记住每位用户的学习历史， 在后续复习和问答中复用这些记忆，实现"越用越懂你"的学习体验。

解决的痛点

  • 📌 学习记录分散 — 笔记散落在各处，难以系统回顾
  • 📌 复习缺乏针对性 — 不知道哪些知识点需要重点复习
  • 📌 学习进度不可见 — 无法直观了解自己的学习轨迹和投入

技术架构

Qoder 项目全程由 Qoder 智能体开发完成（需求分析、编码、调试、部署）
PowerContext 提供记忆存储（remember）、语义检索（search）和上下文组装（context/prepare）能力
FastAPI Python 后端框架，提供 RESTful API 并桥接 PowerContext 服务
Qoder Sites 项目网站通过 Qoder Sites 发布，支持公开访问

PowerContext 如何发挥作用

1
记录阶段
用户提交学习记录 → 后端调用 POST /v1/memory/remember → PowerContext 存储为带标签的记忆条目
↓
2
检索阶段
用户发起复习/问答 → 后端调用 POST /v1/memory/search → PowerContext 按语义相似度返回相关记忆
↓
3
上下文组装
后端调用 POST /v1/context/prepare → PowerContext 将相关记忆组装为有界上下文 → 返回给前端展示

本地运行（完整功能）

# Windows PowerShell，Python 3.11+
# 在参赛仓库的 qoder 目录执行
cd qoder
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 启动真实 PowerContext 和学习应用
.venv\Scripts\python.exe tools\run_local.py

# 打开 http://127.0.0.1:8080

# 自动验收：真实记忆读写和重启恢复
.venv\Scripts\python.exe tools\verify.py

验证样例

样例 1：记录学习并查看统计

  1. 打开应用，点击「记录学习」
  2. 填写：主题「线性代数 - 矩阵乘法」，时长 45 分钟，难度中等，掌握程度 7/10
  3. 点击保存 → 切换到「学习面板」
  4. 预期：显示 1 条记录，45 分钟，1 个主题

PowerContext 验证：调用 POST /v1/memory/search 查询「矩阵」应返回刚记录的条目

样例 2：智能复习检索

  1. 记录 2-3 条不同主题的学习
  2. 点击「智能复习」，输入关键词「矩阵」
  3. 预期：显示相关学习记录和上下文摘要

样例 3：学习问答

  1. 点击「学习问答」，输入「我学过哪些数学内容？」
  2. 预期：基于 PowerContext 记忆返回个性化建议
