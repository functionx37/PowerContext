端侧运行与降级

Transformers.js 3.8.1 / ONNX Runtime Web 在 Worker 内真实计算。显式配置 device: webgpu, dtype: fp16；探测 adapter 与 shader-f16。缺失、初始化或推理失败时自动改用 wasm / q8 并显示原因。WASM 单线程。模型实例复用，配置切换释放。

seekdb 存储与混合检索

seekdb-js 1.4.0；本次嵌入式 seekdb 1.4.0.0。每知识库独立 Collection，保存 document、VECTOR(512)、metadata；HNSW cosine（m=16，ef_construction=200）及 IK smart 全文索引。

hybridSearch(query, knn.queryEmbeddings, rank.rrf) 由数据库 DBMS_HYBRID_SEARCH 完成融合（RRF constant=60）。应用端不拼合两路结果，后端不计算 embedding。另以 seekdb 表存完整原文和集合模型指纹。

状态与优化

来源及分块 SHA-256 固定 ID，重复导入跳过已提交块，失败可重试。180 字符分块、30 重叠、256 token 上限。默认长度排序、batch8、一次导入统一刷新 dbms_index_manager.refresh()，刷新失败明确报告。

请求携带集合 ID 与模型指纹；切换清空旧结果并使旧请求失效。连接队列串行保护 SDK 会话变量；实验用独立临时集合并清理。原文及向量会写入配置的 seekdb，推理始终在当前浏览器。

复现

npm ci → npm run model:fetch → npm run dev，默认本机嵌入式；另提供 Docker Server 配置。浏览器“性能实验室”可重跑并导出逐次 JSON。5 项核心测试、真实数据库集成测试、生产构建均通过。
